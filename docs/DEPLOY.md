# 公開手順（シンクラウドへのアップロード）

新しい版は「`public/` フォルダの中身をサーバーに置くだけ」で動きます。データベースの作成もコマンドの実行も要りません。最初に誰かがアクセスしたときに、必要なファイルが自動で作られます。

> 管理画面のメニュー名は、私のほうで実際の画面を確認できていません。一般的なレンタルサーバーの名前で書いているので、違っていたら近い名前のメニューを探してください。

## 0. 今のサイトをバックアップする（必須）

今サーバーにあるファイル（PHPファイルを含む）を、上書きする前にMacへ保存しておきます。新しい版で困ったときに元に戻すためです。

1. サーバー管理画面の「ファイルマネージャー」を開くか、FTPソフト（Mac なら [Cyberduck](https://cyberduck.io/) や FileZilla）でサーバーに接続します。
2. kappacontainer.com の公開フォルダ（多くの場合 `kappacontainer.com/public_html/`）を開きます。
3. 中身をすべてMacにダウンロードし、`kappacontainer-backup-日付` のような名前のフォルダに保存します。

## 1. PHPのバージョンを確認する

管理画面の「PHP Ver.切替」などのメニューで、kappacontainer.com の PHP が **8.1以上** になっていることを確認します。古い場合は 8.2 か 8.3 を選びます。新しいコードは 8.1 以降の書き方を使っているため、古いバージョンだとエラーになります。

## 2. ファイルをアップロードする（手動の場合）

1. GitHub のこのリポジトリで「Code」→「Download ZIP」を押し、Macで展開します。
2. 展開したフォルダの中の **`public` フォルダの中身** を、公開フォルダ（`public_html/`）にアップロードします。`public` フォルダそのものではなく、その中身を入れてください。
   - アップロードするもの：`index.html`、`assets/`、`api/`
   - `api/_data/.htaccess` も忘れずにアップロードしてください。これがないと、進捗のデータベースが外から見えてしまいます。
   - Macでは `.` で始まるファイルが隠れています。Finderで `Command + Shift + .` を押すと表示されます。
3. 古い版の `index.php` などが残っていると、そちらが優先して表示されることがあります。バックアップを取ったうえで、古いファイルは削除するか、別の名前に変えてください。

## 3. 動作確認

1. https://kappacontainer.com を開き、アイテムがアイコン付きで表示されることを確認します。初回は tarkov.dev から取得するので、数秒かかります。
2. アイテムを押して、チェックが付くことを確認します。
3. 「合言葉を発行する」を押して、合言葉とQRコードが表示されることを確認します。
4. スマホでQRコードを読み取り、同じ進捗が表示されることを確認します。
5. https://kappacontainer.com/api/_data/sync.sqlite を開いて、**「Forbidden」（アクセス禁止）と表示されること**を確認します。ファイルがダウンロードできてしまう場合は、`.htaccess` が効いていません。

## 4.（任意）GitHub から自動でアップロードする

設定しておくと、GitHub の main ブランチに変更が入るたびに、サーバーへ自動でアップロードされます。手でアップロードする手間がなくなります。

1. サーバー管理画面で FTP アカウントの情報（ホスト名・ユーザー名・パスワード）を確認します。
2. GitHub のこのリポジトリで「Settings」→「Secrets and variables」→「Actions」→「New repository secret」を開き、次の4つを登録します。

| 名前 | 入れる値 |
|---|---|
| `FTP_SERVER` | FTPホスト名（例：`sv12345.example.jp`） |
| `FTP_USERNAME` | FTPユーザー名 |
| `FTP_PASSWORD` | FTPパスワード |
| `FTP_SERVER_DIR` | 公開フォルダのパス。最後に `/` を付けます（例：`/kappacontainer.com/public_html/`） |

3. 「Actions」タブ →「Deploy to server」→「Run workflow」を押すと、すぐにアップロードされます。
4. 登録していない間は、このワークフローは何もしないで終わります。

**Secrets（シークレット）** は、パスワードなどを暗号化して保存しておく場所です。コードには書かれないので、公開リポジトリでも他の人には見えません。

## よくあるトラブル

| 症状 | 原因と対処 |
|---|---|
| 「アイテム一覧を読み込めませんでした」と出る | PHPのバージョンが古いか、サーバーから外部（tarkov.dev）への通信がブロックされています。ファイルマネージャーで `api/_data/` にファイルが作られているか見てください。 |
| 同期ボタンを押すとエラーになる | `api/_data/` フォルダにPHPが書き込めない可能性があります。フォルダの権限（パーミッション）を `755` か `705` にしてください。 |
| 古い画面が表示される | ブラウザの古い表示が残っています。`Command + Shift + R` で再読み込みしてください。それでも古い場合は、古い `index.php` が残っていないか確認してください。 |

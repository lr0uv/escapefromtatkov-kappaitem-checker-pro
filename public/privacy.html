プライバシーポリシー

最終更新：2026年10月18日

Kappaチェッカー（kappacontainer.com、以下「本サイト」）は、登録なしで使えることを大切にしています。本サイトが扱う情報と、その使い道は次のとおりです。

1. お使いの端末に保存する情報

チェックした進捗と表示の設定（モード、絞り込み、表示言語など）は、ブラウザの保存領域（localStorage と IndexedDB）に保存します。これらはお使いの端末の中だけにあり、合言葉を発行しない限りサーバーには送りません。Cookie は使っていません。

2. 合言葉で同期するときにサーバーへ保存する情報

  • 保存するのは「どのアイテム・条件にチェックを付けたか」と、その操作の時刻だけです。名前・メールアドレス・ゲーム内のアカウント情報などは受け取りません。
  • 合言葉そのものは保存せず、元に戻せない形に変換した値（ハッシュ）で進捗を管理します。
  • サーバーの故障に備えて、進捗データベースを1日1回コピーし、7日分を保管します。

3. アクセスの記録

  • 同期や共有リンクの使いすぎを防ぐため、IPアドレスを元に戻せない値（ハッシュ）に変換して、10分ごとのアクセス回数だけを数えます。この記録は短時間で削除します。
  • 本サイトを置いているレンタルサーバー（シンレンタルサーバー）は、一般的なWebサーバーと同様に、IPアドレスやブラウザの種類などのアクセスログを記録します。

4. 外部のサービス

  • 文字の表示に Google Fonts を、アイテムのアイコン表示に tarkov.dev の画像を使っています。これらを読み込む際、各サービスにはお使いの端末のIPアドレスなどが送られます。
  • 「進捗をXにポスト」やWikiへのリンクは、押したときだけ X（旧Twitter）や Escape from Tarkov Wiki を開きます。
  • 現在、本サイトはアクセス解析ツールや広告を使っていません。今後導入する場合は、このページを更新してお知らせします。

5. データの削除

  • 端末の進捗は、ブラウザのサイトデータを消すと削除されます。
  • サーバーに保存した進捗の削除を希望される場合は、下記の連絡先に「閲覧専用リンク」を添えてご連絡ください。合言葉は他の人に見られる場所に書かないでください。

6. お問い合わせ

ご意見・不具合の報告・削除のご依頼は GitHub の Issues で受け付けています（投稿内容は公開されます）。

本サイトは非公式のファンツールで、Battlestate Games とは関係ありません。Escape from Tarkov は Battlestate Games の商標です。
